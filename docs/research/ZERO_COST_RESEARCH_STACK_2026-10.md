# Near-Zero-Cost Public-Web Research Stack — 2026-10-01

## Decision

Run public-web research from the Hetzner host, not the Mac: `SearXNG -> Crawl4AI/trafilatura -> local BGE rerank -> free-model synthesis`. Keep the current paid providers as *disabled-by-default, explicit opt-ins*, not as the normal fan-out. This removes the Mac's unreliable foreign-site path and places ordinary web traffic on the US-hosted server. Never send customer/case data, secrets, or authenticated pages to this stack or to any `:free` model.

This is “near zero”, not an SLA: hosting is already sunk cost, upstream indexes can throttle/block a datacentre IP, and every hosted free quota can change. The evidence below is current as checked on 2026-10-01. All linked URLs were opened during verification. Exact quotas have a single authoritative issuer; where an exact number is stated, the issuer's current pricing/rate-limit page is deliberately the source of record rather than a stale third-party copy.

## What exists today

`src/automation/tech_radar.py` builds 7 deep queries and calls all three search clients. `src/automation/web_intelligence.py` then tries Firecrawl before Jina Reader, crawls up to 15 pages, and submits one Jina rerank request. It sends at most 42,000 characters of gathered context to one `cheap`-tier synthesis call (`max_tokens=8,000`), with up to two 6,000-token repair calls. The configured default provider order is Tavily, Exa, Brave; crawl is Firecrawl, then Jina; rerank is `jina-reranker-v2-base-multilingual`. `docs/SYSTEM_MAP.md` confirms the required search/crawl keys are absent from Actions, while `config/models.yaml` correctly restricts free models to non-sensitive work.

For one `deep=True` run before multilingual site-adapter traffic, that is 21 paid-search requests (7 × 3), <=15 Firecrawl scrapes and 1 hosted rerank. At 20 runs/month it is 420 searches/provider, <=300 scrapes, 20 reranks, and 20 primary syntheses (up to 60 with repair). This memo's cost model uses that observable envelope, not a hoped-for average.

## Rerank: local BGE, not a hosted bill

Use `BAAI/bge-reranker-v2-m3` locally (CPU) on no more than 15 candidates × 512 tokens, with a 30 s deadline and search-order fallback. It is directly loadable with `transformers`; measure quality/latency on Persian and English before promotion. Do **not** self-host `jina-reranker-v2-base-multilingual` for commercial work: its model card is CC-BY-NC-4.0. [BGE model card](https://huggingface.co/BAAI/bge-reranker-v2-m3), [BGE integration](https://github.com/FlagOpen/FlagEmbedding/blob/master/examples/finetune/reranker/README.md), [Jina licence](https://jina.ai/models/jina-reranker-v2-base-multilingual/)

The current Jina API is a safe temporary free-key fallback (**100 RPM, 100K TPM**, shared across Reader/Embedding/Reranker; new keys get 10M tokens) but is not “free forever”: it is token-priced after the starter balance and its dashboard recommends auto top-up. Disable auto top-up. [Jina rate table](https://jina.ai/en-US/reranker/), [Reader terms](https://jina.ai/reader/), [Jina pricing FAQ](https://jina.ai/en-US/reranker/)

Do not deploy any of these agents first. The existing `TechRadarAgent` already has a bounded source count and offline fixture; adding an agent before fixing provider order creates unbounded search/token loops. “Token usage per report” is not a portable factual constant: source count, page length, retries and model reasoning change it. The proposed hard ceiling is 20k model tokens/run (normally about 12k input + 3k output + room for planning), logged from provider usage; a cap is the only defensible number.

For free inference: the owner's Mac OmniRoute route is suitable for Mistral Codestral and Groq GPT-OSS-120B, but is not a server dependency. Groq's published free-plan base limit for `openai/gpt-oss-120b` is **30 RPM, 1,000 RPD, 8K TPM, 200K TPD**; this is insufficient for wide parallel research but ample for serial 20-run/month synthesis. OpenRouter's zero-balance free tier is **50 requests/day** and its free pool changes; use it only after Groq/OmniRoute and only for public text. [Groq limits](https://console.groq.com/docs/rate-limits), [GPT-OSS model](https://console.groq.com/docs/model/openai/gpt-oss-120b), [OpenRouter plan](https://openrouter.ai/pricing/)

Codex CLI `--search` is useful for owner-operated, one-off research: official OpenAI documentation says it fetches live search, while cached is the local default and ChatGPT-plan usage is included subject to account/workspace limits. It is **not** an unattended service API and must not be treated as a free production crawler. [OpenAI web search](https://learn.chatgpt.com/docs/web-search), [OpenAI pricing](https://learn.chatgpt.com/docs/pricing), [OpenAI authentication](https://learn.chatgpt.com/docs/auth)

## Monthly cost model: 20 deep research runs

Assumptions: 7 core queries/run, 15 pages/run, 15 × 3,000-character rerank candidates, one primary synthesis. Figures exclude the existing Hetzner price and owner subscription; they are incremental API cost. “$0 within free pool” is not a promise of availability.

| Component | Current implementation envelope | List cost / free-pool outcome | Proposed default |
| --- | --- | --- | --- |
| Tavily | 420 searches | 420 credits <= 1,000 free; $0 **only if** basic calls are one credit | 0; SearXNG/DDGS |
| Exa | 420 searches | $2.94 list, <= $10/month free credit | 0; disabled emergency adapter |
| Brave | 420 searches | $2.10 list, <= $5/month credit/1,000 requests; card required | 0; SearXNG engine only |
| Firecrawl | <=300 basic pages | <=1,000 free credits; $0, but 403/404 consume credits | 0; Crawl4AI + trafilatura |
| Jina rerank | ~225k input tokens/month (rough 15×3k chars×20/4) | dollar value cannot be calculated from current public page; it is a starter balance then token purchase | 0; local BGE |
| LLM synthesis | <=20 primary calls, 8k output cap plus repairs | model-dependent; `config/models.yaml` price is the source of truth. A 20k-token/run ceiling is 400k tokens/month, $0 if the public free route is available. | Groq/OmniRoute first, OR `:free` last; hard ceiling |
| **Incremental total** | all current providers enabled | **$0 only while every free pool holds; otherwise unknown Jina + $0.008 Tavily + $7/1k Exa + $5/1k Brave + Firecrawl PAYG** | **$0 API spend target; fixed Hetzner capacity only** |

The calculated current stack can fit several free trials at this volume, but it is not cost control: it fans out before judging quality, has no consolidated per-provider quota guard, and the current Firecrawl-first path spends a credit even for some failures. Quality risks in the free stack are lower search recall/freshness, datacentre blocking, no commercial anti-bot proxy, BGE CPU latency, free-model JSON/citation failures, and limits that cause a partial report. Mitigate with source-count/status gates, per-provider traces, deduplication, citations required for every finding, and `DEGRADED` rather than a confident report when fewer than three independent sources survive.

### Quotas that can silently charge money

These are product-account controls, not merely code paths: verify the dashboard settings before every test. [Brave billing](https://api-dashboard.search.brave.com/documentation/resources/help-feedback), [Exa pricing](https://exa.ai/pricing), [Tavily pricing](https://help.tavily.com/articles/8816424538-pricing), [Firecrawl pricing](https://www.firecrawl.dev/pricing?dub_id=dUpgqNt9nSs92LTs&via=lokesh-kapoor), [Jina Reader](https://jina.ai/reader/), [OpenRouter pricing](https://openrouter.ai/pricing/)

1. Brave: auto-reload/prepay can charge the card after $5 credit; a card hold is still required.
2. Exa: adding a payment method/PAYG converts overflow to usage billing.
3. Tavily: PAYG is $0.008/credit; do not enable it.
4. Firecrawl: PAYG is available on paid plans; 403/404 cost one credit and extra formats cost more.
5. Jina: a free API key has a 10M starter balance, then paid token packages; auto top-up is explicitly offered.
6. OpenRouter: `:free` is rate-limited and transient; a non-`:free` fallback or funded key can bill. Pin `:free` and reject any other suffix.

4. Add `src/automation/local_reranker.py`: BGE adapter with 15-document/512-token/30-second ceiling and deterministic score-order fallback. Test it with a tiny fake backend in `tests/automation/test_local_reranker.py`; benchmark real weights separately on the Hetzner box.
5. Add `docker/research-stack/docker-compose.yml` and `docker/research-stack/searxng/settings.yml`: private SearXNG JSON endpoint + Valkey + reverse-proxy/IP limiter. Smoke-test against `example.invalid` and the offline client; do not expose JSON unauthenticated.
6. Add `scripts/research_stack_smoke.py`: a public, fixed 10-query corpus that compares current fake adapters, SearXNG/DDGS, extractors and BGE; emit source count, duplicate rate, latency, 429s and token usage without invoking paid APIs.

## Hetzner installation and footprint

Install only SearXNG + Valkey and Crawl4AI initially. Reserve 1 GB RAM/1 GB disk for SearXNG+Valkey (operator cap/estimate, not an upstream guarantee) and **at least 4 GB RAM available** for Crawl4AI, as documented upstream; reserve 5 GB disk for its image/browser cache before pull and measure `docker system df`. This leaves roughly 7 GB RAM and 25 GB disk from the stated free capacity. Keep trafilatura in the application virtualenv. Do not install Firecrawl, Local Deep Research, Ollama, or a local LLM on this 12-GB box initially. Add local BGE only after its CPU benchmark: reserve 3 GB RAM and 2 GB disk for the 568M-weight service, run it serially, and retain search-order fallback. The documented Crawl4AI minimum and SearXNG limiter dependency are the hard evidence; all allocation figures are conservative operational budgets to validate before deployment.
