# راهنمای مالک — سؤال‌های پرتکرار و کارهای روزمره

(فارسی؛ به‌روزرسانی: ۲۰۲۶-۰۹-۳۰. وضعیت لحظه‌ای در `docs/STATE.md` است.)

## ۱. سامانه از چه ساخته شده؟
| بخش | چیست | کجاست |
| --- | --- | --- |
| سایت (Next.js) | ظاهر ghazihoushmand.ir | کانتینر `roxira_enterprise_frontend` |
| هسته‌ی حقوقی (FastAPI) | پرسش حقوقی، لایحه، پرداخت، ورود پیامکی | کانتینر `roxira_app_prod` |
| جست‌وجوی قوانین | Qdrant، مجموعه‌ی `iran_laws_v2` | کانتینر `qdrant_prod` |
| پایگاه داده | Postgres + PgBouncer، Redis | کانتینرها |
| درگاه | nginx، فقط پورت‌های ۲۲/۸۰/۴۴۳ | `roxira_nginx_prod` |
| مدل‌های زبانی | OpenRouter (DeepSeek ارزان) با کلید `roxira-prod-chat` | فایل `.env` سرور |
| ایجنت‌های ساخت | GitHub agent، `rx` روی مک | مک شما و GitHub |

## ۲. هر کار جدید چطور انجام می‌شود؟
1. کار را به‌صورت issue در GitHub بنویسید (یا از چت Sonnet بخواهید).
2. اجرا: `rx <شماره>` یا چند کار هم‌زمان `rxall 1 2 3` در ترمینال مک.
3. PR که ساخته شد را در چت Sonnet بدهید تا بازبینی و ادغام شود.
4. نصب روی سرور فقط با تأیید شما (یک سؤال) و با `scripts/ops/deploy.sh`.

## ۳. اگر چیزی خراب شد
- سایت بالا نیست: GitHub → Issues → برچسب `incident` (بررسی خودکار هر ۶ ساعت). خودتان: `curl -I https://ghazihoushmand.ir/`.
- چت هوش مصنوعی خطا می‌دهد: اول کلید سرور (401؟). کلید تازه در OpenRouter بسازید، سقف روزانه بگذارید، با دستور `ssh` مرحله‌ای که در چت داده شد به `.env` سرور بدهید.
- بعد از نصب خراب شد: `scripts/ops/rollback.sh <service>`.
- `rx` خطای ۴۰۳ می‌دهد: IP مک/VPN مسدود شده؛ VPN را عوض کنید.
- `rx` می‌گوید «no changes»: کار قبلاً انجام شده یا مدل توانایی‌اش را نداشت؛ شماره‌ی کار انجام‌شده را دوباره نزنید.

## ۴. هزینه‌ها (چه چیزی پول می‌گیرد؟)
- OpenRouter: مصرف واقعی؛ سقف روزانه‌ی هر کلید را در https://openrouter.ai/settings/keys نگه دارید (سایت ۳ دلار، ایجنت/مک ۲ دلار).
- GitHub Team: حدود ۴ دلار در ماه. **گزینه‌های پولی Advanced Security (۱۹ و ۳۰ دلار) را روشن نکنید.** معادل رایگانش (gitleaks، بررسی هفتگی وابستگی‌ها، Dependabot) فعال است.
- Anthropic/Claude: سهمیه‌ی هفتگی. کار اجرایی را به Claude ندهید.

## ۵. امنیت (قوانین ثابت)
- کلید را در چت، کد یا گیت ننویسید؛ فقط در فایل محلی یا `.env` سرور.
- روی سرور واقعی هیچ ایجنت یا کد تولیدشده‌ی مدل اجرا نمی‌شود.
- تغییر پایگاه داده‌ی واقعی فقط با تأیید صریح شما.
- ادغام فقط با PR و بررسی‌های سبز.

## ۶. سؤال‌های احتمالی آینده
- **آیا همه‌ی قوانین ایران را دارد؟** نه؛ ۸ قانون. برنامه: `docs/LEGAL_COVERAGE_ROADMAP.md`.
- **جواب حقوقی قابل اتکاست؟** جایگزین وکیل نیست؛ اعتبارسنجی وکیل لازم است.
- **بسته‌های توکن چه شدند؟** نمایشی «به‌زودی»؛ فعلاً بک‌اند ندارند.
- **می‌شود مدل را عوض کرد؟** فقط در `config/models.yaml`؛ بعد از آزمون `scripts/eval_cheap_tier.py`.
- **چطور قیمت را عوض کنم؟** متغیر `PRICE_TOMAN_<PLAN>` در `.env` سرور و راه‌اندازی دوباره‌ی برنامه.
- **پشتیبان‌گیری؟** ساعتی روی سرور + کپی روزانه روی مک؛ آزمون بازیابی ماهانه: `docs/ops/RESTORE_DRILL.md`.
